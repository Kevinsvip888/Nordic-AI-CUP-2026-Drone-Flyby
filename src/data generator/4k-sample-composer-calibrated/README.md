# 4K 样本合成器 · 独立标注校准版

**优先阅读 [使用说明.md](使用说明.md)。** 使用原 objects 内的 16 张 PNG，按文件哈希自动匹配参考标注框；生成时同步变换参考框。原生成器和原 PNG 不变。以下为基础操作说明，校准区别以使用说明为准。

完全离线运行。解压全部文件后打开 `dist/index.html`，无需安装依赖。

## 编辑已有图像的标注（默认）
1. 选择一张 3840×2160 的图像作为背景，可包含已有物体。
2. 导入 JSON，保持“JSON 导入方式”为“标注框编辑 · 无需 PNG”。
3. 全部 bbox 矩形框和 object_id 会立即显示。导入顺序可互换，无需任何 PNG 素材。
4. 点击框内部或在左侧列表选择；拖动内部移动，拖动四边/四角的八个控制点调整大小。
5. 右侧可编辑 object_id、中心坐标或 x1/y1/x2/y2。方向键微调，Shift 加速；支持复制、删除和撤销/重做。
6. 导出 JSON，默认文件名为原文件名加 _modified。frame、pose 和额外字段保留，object_counts 自动重新统计。

编辑框不会移动原图中的真实物体。框的移动/调整限制在画布内；非法或越界的导入坐标会提示错误。
纯标注框是轴对齐矩形，不支持旋转。原图标注时背景变换锁定；导入框时背景变换重置为原始位置和大小，以保持 JSON 与原图坐标一致。顶部“视图”缩放仍可正常使用。

## PNG 合成（保留原流程）
- 使用干净背景，上传最多 16 张 PNG。点击素材或拖到画布，支持移动、缩放、旋转、复制和图层顺序调整。
- 若需按 JSON 恢复 PNG 实例，先把“JSON 导入方式”改为“PNG 合成 · 匹配同名素材”，再导入 JSON。
- 同名素材按 object_id 匹配；未匹配标注继续保留。缺少素材时暂停 PNG/ZIP 导出，仍可单独导出 JSON。
- 上传 PNG 不会自动替换默认导入的纯标注框；模式选择只影响下一次 JSON 导入。
- 已校准 PNG 的 bbox 按原标注参考矩形同步变换计算；未校准 PNG 按整张 PNG 矩形计算。不扣除遮挡面积。JSON 没有旋转信息，恢复 PNG 时用零旋转按框尺寸及参考偏移放置，不是精确姿态恢复。

## 导出与保存
- JSON 输出 bbox 格式为 [x1, y1, x2, y2]，坐标基于 3840×2160 原图。
- PNG 和 ZIP 中的样本图不含编辑标注框、标签和控制点，避免将标注画进训练图片。
- 不会主动写回导入的 JSON，下载会生成新文件。
- JSON 不是完整工程存档，不包含素材、背景变换、PNG 旋转或图层信息；目前无自动保存。关闭/刷新前请导出。
- 缩小或移动合成背景时露出深色填充区域，pose 不会自动改变。

## 测试
`node tests/regression.cjs` 可执行无额外依赖的逻辑回归测试。32 项检查通过，新增真实 16 类素材校验、参考框变换及边缘测试；测试素材仍取同级原 objects 文件夹。
测试使用模拟 DOM/canvas，覆盖导入、绘制调用、八方向调整、拖动、精确坐标、JSON 往返、撤销和导出。
