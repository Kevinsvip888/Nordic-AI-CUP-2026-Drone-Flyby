# 1.4 — 无需 PNG 的标注框编辑

- JSON 默认直接创建可编辑矩形框，显示所有 bbox 和 object_id。
- 支持内部拖动、八个控制点调整宽高、四坐标输入、命名、删除、复制及撤销。
- 纯标注框锁定背景变换以保留原图坐标，视图缩放仍可使用。
- 标签和框仅用于编辑预览，导出样本 PNG 不含这些元素。
- JSON 导入方式可改选旧版 PNG 合成流程；后续上传 PNG 不会替换纯标注框。
- 24 项模拟 DOM/canvas 回归测试通过；未做真实浏览器视觉测试。

# 1.3 — 用户体验与错误修复

## 已修复

1. 缺少 PNG 时仍允许导出带有不存在物体标注的图片/ZIP。现在禁用，并显示缺失素材名称；单独 JSON 导出不受影响。
2. ZIP 异步生成过程中继续编辑可能导致 PNG 与 JSON 状态不同。现在同步捕获一对快照后再编码；重复导出被阻止，编码失败有提示。
3. 撤销遗漏 frame、pose、文件名、原 JSON 字段、背景文件和素材列表。现在一起恢复，删除素材后撤销也能恢复引用。
4. 外部文件拖放被空字符串转换为索引 0，误添加第一个素材。现在区分素材拖动和文件拖放。
5. 视图达到缩放上限后宽度仍改变。现在限制真实画布显示尺寸。
6. 导入 JSON 丢失额外字段；特殊名称（例如 __proto__）的计数错误。现在保留字段并正确统计。
7. 中文 ZIP 文件名没有 UTF-8 标记。已修复。
8. 未匹配素材的现有标注在再次导入时没有确认。现在替换前确认。
9. 导入带 BOM 的 JSON 失败、无效 frame/pose 被静默转换。现在兼容 BOM，并拒绝非法数据。
10. 编辑 object_id 会删除句点后的内容。现在保留原始名称，只去除首尾空格。
11. 非等比导入物体缩放到边界时比例变化、取消拖动没有结束交互。已修复。
12. 并行点击文件导入导致素材上限和状态竞争。现在串行处理，并提示稍候。

## 易用性

- 缺少素材清单直接展示。
- 增加更换背景按钮、实例选择列表和回到中心按钮。
- 工具栏自动换行；缩放后的画布起始区域可滚动访问。
- 修复背景选择区域装饰层可能遮挡点击的问题。
- 提高常用标签字号，增加键盘焦点提示。
- 刷新/离开页面前提醒；明确 JSON 不是工程存档。

## 测试范围

16 项自动化回归检查全部通过（含用户示例 11 个标注的 JSON 往返）。测试使用模拟 DOM/canvas，覆盖导入、精确 bbox 恢复、字段保留、缺失素材保护、撤销重做、拖放、缩放限制、导出快照及 ZIP CRC/UTF-8。没有完成真实浏览器视觉、下载弹窗或真实 PNG 像素测试。
